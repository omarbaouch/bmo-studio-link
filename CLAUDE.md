# BMO Studio Link — publication YouTube centralisée

Ce dépôt ne contient que le système de publication. Pour publier, ajouter un fichier `publications/*.json`
(format dans README.md) et pousser sur `main` : le workflow `.github/workflows/publier-youtube.yml` fait le reste.
- Ne jamais écrire, afficher ni committer de clé : elles sont dans les secrets GitHub du dépôt.
- Les vidéos doivent être accessibles par un lien public (pas de dépôt privé).
- Un push = une publication réelle sur une vraie chaîne : ne déposer une fiche que sur demande d'Omar.
- Tant que l'audit Google n'est pas validé, les vidéos arrivent en privé.
